# JMH (Java Microbenchmark harness)

JMH is the standard Java Microbenchmark Harness developed by OpenJDK to write, run, and 
analyze accurate performance benchmarks for code targeting the Java Virtual Machine (JVM)

Its a framework made for answering questions like:

"Which of these two pieces of Java code is actually faster and by how much?"

Also, it is a micro-benchmark, don't use it to benchmark "How fast is my REST API?"

For that purpose, tools like JMeter are there
